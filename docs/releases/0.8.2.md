## Noita configuration safety

- Invalid or missing Noita save directory / `mod_config.xml` now enters configuration-only mode: preset editing and import/export stay local while Noita syncing is paused.
- Save Monitor, Noita-facing backups/restores, and Open XML are blocked until configuration is valid again; an active monitor stops if the configuration disappears.
- Recovery survives relaunch. When `mod_config.xml` becomes available again, Hallinta requires a choice:
  - apply the selected preset to Noita, or
  - keep the detected Noita setup as a newly named preset (existing names are never overwritten).
- The app banner and empty-list messaging distinguish configuration-only recovery from a valid empty mod list.

## Reliability

- File-watch recovery no longer rewrites settings on every failed poll; only real state transitions persist.
- Whitespace-only paths are treated as unconfigured across load, save, monitor, and backup paths.
- Expanded regression coverage for configuration-only mode, reconciliation choices, and Open XML/backup guards.

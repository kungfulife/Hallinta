## Updates

- Replaced Hallinta's custom updater engine with the maintained `self_update`
  and `self-replace` stack.
- Official updates now use signed archives verified before installation; the
  portable executable remains available for manual download.
- Update installation now shows a simple protected install state without
  download cancellation or byte progress.
- Hallinta still waits for Save Monitor safety and a final snapshot before
  installation, then resumes the active monitor session after restart.
- Removed Hallinta's custom helper, handoff, readiness, and automatic rollback
  protocol. A failed post-install launch now requires downloading a portable
  release manually.

## Windows build identity

- File version and Product version in Windows Properties now match the package
  version from `Cargo.toml`.
- Release CI verifies tag, Cargo version, executable version metadata, signed
  archive contents, and both uploaded asset digests before publication.

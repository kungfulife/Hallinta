## Updates

- Added safe in-app updates through official GitHub Releases for Windows 11 portable builds.
- Added verified download progress, cancellation, retryable network errors, and an interaction lock during updates.
- Active Save Monitor sessions now take a final snapshot before an update and resume after restart. A snapshot failure aborts the update and keeps Hallinta open.
- Added atomic executable replacement, first-frame readiness confirmation, and automatic rollback when the updated app cannot start.

## Save Monitor and backups

- Improved snapshot scheduling, live session refresh, backup workflows, and interrupted-session recovery.
- Kept mod editing available during monitoring while safely deferring external-change prompts.
- Hardened persistence, archive validation, and invalid save-data handling.

## Interface

- Refined the normal and compact layouts, including aligned action rows and clearer monitoring controls.
- Updated dependencies and expanded regression coverage.

## Installation note

- Version 0.8.1 is the first self-updating release. Install this portable executable manually once; later official releases can update it in place.

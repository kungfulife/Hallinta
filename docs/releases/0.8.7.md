## Interface

- Manage Sessions now shows each session's stored snapshots against the configured per-session maximum.
- Update descriptions now use a clearer lavender hierarchy for headings and bullets in both dark and light modes.
- Update prompts link directly to the offered GitHub release, and Settings includes a shortcut to the Hallinta repository.
- Removed redundant update-installation copy and the unsupported arrow glyph from Back to Sessions.

## Compatibility

- No settings, snapshot, session, or other stored-data migration is required.

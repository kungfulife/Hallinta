## Recovery and updates

- Version-upgrade backups now appear in Manage Backups with the same restore and
  delete controls as manual backups. New upgrade archives are written into the
  shared `backups/` folder; older files under `upgrade_backups/` remain
  restorable.
- Dismissing an available update remembers that exact version so startup checks
  stay quiet. A newer release prompts again, and Settings → Check for Updates
  always re-offers the current candidate.
- Accepting an update clears a previous dismiss so later offers stay clean.

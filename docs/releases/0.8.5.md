## Save Monitor

- Optional auto-start when Noita is running (and optionally the Entangled Worlds
  `noita_proxy`), by process name only — not install path.
- One-time prompt: Always or Not now. After that, Auto-start stays Off or Always
  until you change it in Settings (Reset to Defaults restores the prompt).
- "Start on Hallinta launch" remains a separate manual setting.
- Never re-prompts or auto-starts while a monitor session is already running.
  Hallinta does not auto-stop monitoring when the game exits.

## Settings

- Reset to Defaults no longer forces "Noita Configuration Detected" when the
  Noita path is unchanged after auto-detect.
